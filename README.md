## 구현 기능 목록

**문자열 입력**

- [ ] 로또 구입 금액 입력받기
   - “구입금액을 입력해 주세요.” 출력
   - 1000 단위
   - [예외] 빈 입력
   - [예외] 숫자가 아닐 시
   - [예외] 1000으로 나누어지는 숫자가 아닐 시
- [ ] 로또 구입 개수 출력
   - 로또 1장은 1000원
   - “n개를 구매했습니다.” 출력
   - “[8, 21, 23, 41, 42, 43]” 형식
   - 로또 번호는 오름차순
   - Random 값 추출은 `Random.pickUniqueNumbersInRange()`를 활용
- [ ] 당첨 번호 입력받기
   - “당첨 번호를 입력해 주세요.” 출력
   - 쉼표(,)를 기준으로 구분
   - [예외] 빈 입력
   - [예외] 숫자가 아닐 시
   - [예외] 쉼표로 구분한 값이 1~45까지의 숫자가 아닐 시 
   - [예외] 숫자가 중복 시
   - [예외] 숫자가 6개를 초과할 시
- [ ] 보너스 번호 입력받기
   - “보너스 번호를 입력해 주세요.” 출력
   - [예외] 빈 입력
   - [예외] 숫자가 아닐 시
   - [예외] 1~45까지의 숫자가 아닐 시
   - [예외] 숫자가 당첨 번호와 중복 시
- [ ] 당첨 내역 출력
   - “당첨 통계” 출력
   - “---” 출력
   - “3개 일치 (5,000원) - 1개” 형식
- [ ] 수익률 출력
   - “총 수익률은 62.5%입니다.” 형식
   - 소수점 둘째 자리에서 반올림
